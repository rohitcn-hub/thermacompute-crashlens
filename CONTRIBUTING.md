# Contributing

Open an issue with the symptom, Python/engine versions and expected behavior. Attach only invented or explicitly authorized sanitized examples. Include positive, negative and unknown cases for new signatures. Cite the upstream documentation and applicable versions for proposed advice. Do not add automatic commands or network calls to the analysis path.

Run `python -m unittest discover -s tests -v` from the repository root. Clearly label simulated evidence. Never claim an inferred cause is established by one matching phrase. AI-assisted contributions are welcome but contributors must inspect and test them.
